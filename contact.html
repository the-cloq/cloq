FAQ

GENERAL

How does CLOQ by Jase function?

CLOQ by Jase have three modes. The touch sensor on the edge of the frame allows for each mode to be displayed.

Mode 1: Word Clock

This mode displays the time in words, as well as single digits to display the seconds. This mode can also display the current weather ambience. See further down under weather settings.

Mode 2: Digital Clock

This mode displays the time in digital format by using the 16 x 16 matrix to form 7 x 7 digital numerals.

Mode 3: Temperature and weather conditions

This mode displays the current temperature in either Celcuis or Fahrenheit and the weather conditions whether it be clear skies, cloudy, rain or snow. You'll need to set up a free account with openweathermap in order to use this feature.

Where is CLOQ by Jase made?

CLOQ by Jase is made in and shipped from England.


TECHNICAL

Will CLOQ by Jase work in my country?

CLOQ by Jase comes with a standard USB cable plug and a power adapter suitable for the standard power outlet of the country it is shipped to (supported power plug types: US, EU, China, UK, AUS. 120-230 V). To be covered under warranty we require you to only use the USB cable provided.

The power requirements are: 120-230 V. A 5V 2amp plug suitable for the country of delivery is included in the shipment. To be covered under warranty we require you to only use the power adapter provided.

Once the power is back, it will resume from the actual time.

Can I use a different power adapter from the one provided?

You must use the provided power adapter to be covered under warranty.


INSTALLATION

Can I install CLOQ by Jase by myself or do I need a technician?

CLOQ by Jase should be installed by someone with basic technical knowledge who fully understands the installation manual. As the artwork weighs 4.8kg for the Classic and 5.8kg for the Grande, two persons may be required to mount CLOQ by Jase on the wall.

How do I install CLOQ by Jase?

CLOQ by Jase comes with a paper wall plate template which can be used as a guide for the pilot holes to be drilled into the wall. Attachment fixtures are also provided, but please make sure that these are suitable for the material of the wall on which the artwork is to be mounted. Full instructions on how to install CLOQ by Jase are included in the installation manual that comes with the artwork.

How long is the CLOQ by Jase power cable?

The CLOQ by Jase power cable is 3 meters.

How much does CLOQ by Jase weigh?

CLOQ by Jase Classic weighs 4.8kg and the Grande weighs 5.8kg.

Can I install CLOQ by Jase with a hidden cable solution?

Yes, a hidden cable installation is possible. The ideal cable-free installation requires preparing the wall with a recessed power socket behind the artwork. Use suitable wall plugs and screws (max diameter of 6mm) to mount the CLOQ by Jase.

Can CLOQ by Jase be installed in outdoor locations?

No, CLOQ by Jase can only be installed in indoor locations.

Note: Do not install CLOQ by Jase in places with high levels of humidity. The artwork should never be exposed to direct sunlight, very high/low temperatures, moisture or strong vibrations. It should only be operated in temperatures between 10°C and 35°C (50°F to 95°F).

Can I unplug and store away CLOQ by Jase for an extended period of time?

Yes, the artwork will not take any damage by being unplugged and stored away for a longer period of time.
